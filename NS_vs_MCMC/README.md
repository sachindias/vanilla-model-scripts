# Notes On Nested Sampling

---

## What is in this Folder?

The scripts in this folder are for comparing the results from the Nested Sampling and Markov-chain Monte Carlo algorithms.

- **NS_MCMC_comparison_histograms.py** - For comparing results as histograms.
- **NS_MCMC_comparison_violin_plots.py** - For comparing results as violin plots.
See the scripts below for implementation.
- **NS_MCMC_obs_comparison_violin_plots.py** - For comparing posteriors between different GRO J1655-40 observations as violin plots.
- **NS_MCMC_spin_comparison_violin_plots.py** - For comparing posteriors between different spin values (for a single MAXI J1820+070 observation) as violin plots.
